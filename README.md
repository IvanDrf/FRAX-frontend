# FRAX - Frontend (React + TypeScript)

## Описание проекта

Frontend-часть SPA (Single Page Application) для просмотра и добавления факторов риска остеопороза. 
Приложение разработано с использованием **React**, **TypeScript** и **Vite**. 

---

## Страницы

1) Каталог - `src/pages/CatalogPage.tsx` 

2) Лента — `src/pages/ReelsPage.tsx`

3) Добавление — `src/pages/AddPage.tsx`

## Как запустить приложение

```bash
npm install
npm run dev
```
